LoFiGL is a lightweight Python-based 3D engine designed for rapid experimentation. It features an unlit forward rendering pipeline with MSAA and camera-relative (double-precision) positioning for large worlds.
Built on top of OpenGL 4.5 (through ModernGL and pygame), LoFiGL prioritizes simplicity, modifiability, and scriptability — ideal for AI-enhanced game logic, procedural content, and educational graphics research.
